Broken App: Optimization & Bug Fix Report

Проект по поиску дефектов, устранению Undefined Behavior и глубокой оптимизации производительности Rust-приложения.
Выполненные работы
1. Исправление багов и безопасность

В ходе аудита кода (Шаг 2) были обнаружены и устранены следующие дефекты:

    Алгоритмические ошибки: Исправлена экспоненциальная рекурсия в расчете чисел Фибоначчи и неэффективная логика дедупликации.

    Логические ошибки: Исправлен расчет среднего значения (добавлена защита от деления на ноль).

    Аудит безопасности: Проект проверен с помощью Miri. Устранены потенциальные UB (Undefined Behavior). Лог чистого прогона находится в artifacts/miri_report.txt.

2. Регрессионное тестирование

Для предотвращения повторного появления багов добавлены тесты (в src/lib.rs):

    test_fib_regression: проверка граничных значений (0, 1) и корректность больших чисел.

    test_dedup_regression: проверка корректности удаления дубликатов на различных наборах данных.

    test_average_positive_regression: проверка устойчивости к пустым входным данным.

3. Оптимизация производительности

Было проведено профилирование (Шаг 4) с помощью Flamegraph, выявившее «горячие точки» в slow_fib и slow_dedup.
Функция	До (Baseline)	После (Optimized)	Ускорение	Тип оптимизации
sum_even	16.95 µs	15.12 µs	~1.1x	Микро (Iterator)
slow_fib	6.75 ms	240.1 ps	~28,000,000x	Алгоритмическая (O(2n)→O(1)*)
slow_dedup	10.24 ms	21.42 µs	~470x	Алгоритмическая (O(n2logn)→O(nlogn))

*Примечание: Результат в пикосекундах обусловлен оптимизацией компилятора (constant folding) после перехода к итеративному алгоритму.
Артефакты (папка /artifacts)

Для подтверждения результатов в папку artifacts включены:

    bench_before.txt / bench_after.txt: Сравнительные отчеты Criterion.

    miri_report.txt: Подтверждение отсутствия UB при тестировании.

    flamegraph.svg: Визуализация профилирования (узкие места).

    target/criterion/report/: Полные HTML-отчеты с графиками плотности распределения времени выполнения.
